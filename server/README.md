# Запись на консультации «Gubenko Group» (версия 2)

| Адрес | Для кого |
|---|---|
| `/` | Анкета и запись — ссылка из автоответа Instagram |
| `/?b=…` | Личная страница заявки клиента: время, специалист, календарь, перенос, отмена |
| `/admin` | Кабинеты: админ и менеджеры (вход по логину и паролю) |
| `/privacy` | Политика обработки персональных данных |

## Путь клиента (по схеме «Цепочка записи»)
1. Первый экран → анкета: сумма долга (один ответ), имущество и работа (несколько ответов, «Имущества нет» и «Сейчас не работаю» исключают лишнее).
2. Предложение получить план → **«Выбрать дату и время»** или **«Подобрать время с менеджером»**.
3. Дата и время показываются в часовом поясе клиента (можно сменить). Час свободен, пока свободен хотя бы один менеджер; запись уходит менеджеру, у которого в этот день меньше записей.
4. Форма: имя, город, телефон (только российский мобильный), мессенджер для связи (Telegram — с ником, WhatsApp/MAX — по телефону), согласие с версией документа.
5. Страница заявки по ссылке: дата, время, специалист, ссылка на встречу (когда менеджер её вставит), «Добавить в календарь», «Перенести», «Отменить».
6. Если человек ушёл — при возврате продолжает с того же места; после записи сразу открывается его заявка.

Тексты, мессенджеры, список источников и видов услуг — в `funnel.json`. Поля в квадратных скобках заполнить перед запуском.

## Кабинеты
| Кабинет | Что видит | Записи с сайта |
|---|---|---|
| Админ | Расписание всех (фильтр «Все / Наталья / Роман / Моё»), все клиенты, все заявки | Нет — его расписание личное |
| Менеджер (Наталья, Роман) | Только своё расписание и своих клиентов + общие заявки на подбор времени | Да |

В карточке записи: подтверждение накануне (да / нет / перезапись), явка (пришёл / не пришёл / нецелевой), источник, вид услуги, ссылка на встречу, комментарий, перенос и смена специалиста. Над расписанием — заметки дня. Вкладка «Воронка» — сколько людей дошли до каждого шага.

## UTM-метки и источники
Добавьте к ссылке `?utm_source=...` — источник запишется в карточку и в «Воронку» сам:
`https://губенко.онлайн/?utm_source=instagram` → «Нельзяграм (воронка)», `telegram`/`tg`/`max` → «Канал ТГ / MAX», `vk` → «ВК», `youtube` → «YouTube», `yandex`/`direct` → «Реклама», `2gis` → «Карты».
Таблица соответствий — `utm_sources` в `funnel.json`. Незнакомая метка (например, `utm_source=dzen`) попадёт в аналитику отдельной строкой как есть. Без метки — «Нельзяграм (воронка)». Метка запоминается: если человек ушёл и вернулся по ссылке без метки, источник сохранится. `utm_medium`, `utm_campaign` и остальные видны в карточке записи; воронку можно отфильтровать по источнику.

## Установка на сервер (Ubuntu 24.04 / 26.04)
В консоли сервера под root одной командой:
```bash
curl -fsSL https://raw.githubusercontent.com/SK-strategy/zapis-konsultacii/main/deploy/setup.sh | bash -s -- губенко.онлайн
```
Скрипт спросит пароли трёх кабинетов (логины `admin`, `natalya`, `roman`), поставит сайт, HTTPS, автообновление из GitHub каждые 5 минут и ежедневную копию базы (хранится 30 дней). Без домена — `... | bash` (сайт по IP).

## Управление кабинетами (на сервере)
```bash
cd /opt/zapis/server && sudo -u zapis env DATA_DIR=/var/lib/zapis ../venv/bin/python manage.py list-users
… manage.py add-user ЛОГИН "Имя" manager      # или admin
… manage.py set-password ЛОГИН
… manage.py hide ЛОГИН / show ЛОГИН            # убрать менеджера из записи с сайта / вернуть
… manage.py disable ЛОГИН                      # закрыть доступ
```

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что это |
|---|---|---|
| `HOURS` | `6,7,8,9,10,11,12` | Начало консультаций, по Москве |
| `WORKDAYS` | `0,1,2,3,4` | Рабочие дни, 0 = понедельник |
| `DAYS_AHEAD` | `14` | На сколько дней вперёд открыта запись |
| `LEAD_MINUTES` | `60` | Минимум до начала, чтобы записаться |
| `DATA_DIR` | `./data` | Где лежит база (SQLite) |
| `ADMIN_USERS` | — | Для быстрого старта без скрипта: `login:пароль:Имя:роль;…` |

Локально для проверки: `COOKIE_SECURE=0 ADMIN_USERS="admin:пароль:Админ:admin;natalya:пароль:Наталья" python app.py`.
