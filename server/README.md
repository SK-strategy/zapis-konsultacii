# Сервис записи на консультации

| Адрес | Для кого |
|---|---|
| `/` | Страница записи для клиентов — эту ссылку ставим в бота |
| `/admin` | Админка: расписание и клиенты (вход по логину и паролю) |
| `/privacy` | Текст согласия на обработку ПД — **заменить на текст эксперта** |

## Что умеет
- Будни, консультации с 06:00 до 13:00 по Москве, каждый час. Клиент видит время и по Москве, и по своему поясу.
- Один слот — одна запись, даже если двое жмут одновременно.
- После записи — кнопки «Добавить в календарь» (.ics с напоминанием за час) и «Google Календарь».
- Ссылка из бота может подставить данные: `/?name={имя}&phone={телефон}`.
- Админка: неделя по часам, ручная запись, закрыть время, статус (Записан / Пришёл / Не пришёл / Купил), отмена.
- Мини-CRM: клиенты по телефону, поиск, фильтр по статусу, заметки, история записей.

## Запуск на сервере
```bash
pip install -r requirements.txt
export SECRET_KEY="длинная-случайная-строка"
export ADMIN_USERS="olga:ПАРОЛЬ:Ольга;irina:ПАРОЛЬ:Ирина"   # создаются при первом запуске
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```
Сайт должен открываться по HTTPS (иначе вход в админку не сохранится). Для локальной проверки без HTTPS: `COOKIE_SECURE=0`.

## Менеджеры
```bash
python manage.py add-user ЛОГИН "Имя"      # пароль спросит
python manage.py set-password ЛОГИН
python manage.py list-users
python manage.py remove-user ЛОГИН
```

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что это |
|---|---|---|
| `HOURS` | `6,7,8,9,10,11,12` | Начало консультаций, по Москве |
| `WORKDAYS` | `0,1,2,3,4` | Рабочие дни, 0 = понедельник |
| `DAYS_AHEAD` | `14` | На сколько дней вперёд открыта запись |
| `LEAD_MINUTES` | `60` | Минимум до начала, чтобы записаться |
| `EVENT_TITLE` | `Консультация` | Название события в календаре |
| `DATA_DIR` | `./data` | Где лежит база (SQLite). Эту папку нужно бэкапить |

## Размещение на Amvera Cloud

В корне репозитория лежит `amvera.yml` — Amvera сама соберёт и запустит сервис.

1. Создать проект (регион **Москва**), тип «Приложение», подключить этот репозиторий GitHub.
2. Во вкладке «Переменные» добавить **секрет** `ADMIN_USERS` = `login1:пароль1:Имя1;login2:пароль2:Имя2`
   (пользователи создаются при первом запуске; потом пароли меняются через `manage.py`).
3. Дождаться сборки → открыть `https://<проект>-<username>.amvera.io` (запись) и `/admin` (админка).

База (`/data/zapis.sqlite3`) и ключ сессий лежат на постоянном диске и переживают редеплой.
